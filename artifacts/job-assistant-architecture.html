目標與原則

G115 分鐘投遞

看到 JD，草稿從資料庫自動組裝，不從零寫。

G2每份 JD 一次簡短 grooming

最多 3 題、選擇題為主、5 分鐘內，只問會改變這份草稿的事。

G3Grill 長出洞見

工作描述越磨越準，並看出跨職涯的主軸、跨 JD 的缺口。

原則：每次互動的資訊只收一次。 收了就結構化、永久可用；已經回答過的問題不准再問。 缺的事實記進待問題庫，累積後批次問，用編號作答。
文字基調：不張揚、不低下。 不靠語感，而是機械化：每個經歷記錄你的實際角色， CV 動詞只能落在該角色允許的範圍內（見 主張強度階梯）。

元件說明

① JD 分析P2

每份看過的 JD 都存（含沒投的），是市場需求樣本。硬條件寫在 memory/criteria.yaml， Huawei 的教訓：條件不對的機會越早篩掉越省時間。

② 對位矩陣P2

需求逐條對到 atom，分「強／弱／無」。真缺口進 grooming 或 gaps/；表述缺口（bank 有但 master 沒寫）自動補。

③ 事實庫P1

由現在的 experience_bank.md 遷移，一個 atom 一個檔案。只改結構，不改任何事實。 更正不刪舊條目，用 supersedes: 串起來。

④ 互動擷取層P1

每次 grooming／grill 的逐字問答存 sessions/；缺的事實進 open_questions.yaml， 不當場追問。問之前先查，答過的不准再問。

⑤ 組裝P3

優先用 atom 的已核可措辭；新措辭要標出處，核可後回寫，下次直接用。 Synopsys 段落順序鎖定：ILT → SMO → ML-ILT → GPU validation → wrapper(EOU) → imec。

⑥ 規則層部分完成

redline（§3 紅線）與頁數門禁已上線；主張強度階梯與風格檢查在 P4。

⑦ 漏斗已完成

每筆投遞記管道、誰先開口、事件時間軸。狀態、回覆率、待跟進全部從事件推導。

⑧ 洞見迴圈P5

「最近 N 份 JD 裡 X 出現幾次、bank 覆蓋多強」→ 決定下次 grill 挖什麼、哪個缺口值得補學。

atom 長什麼樣子

---
id: ML-01
title: TensorFlow 訓練資料管道擴量
role: initiated-and-led          # 決定 CV 可用的動詞範圍
employer: Synopsys
tags: [ml, tensorflow, data-pipeline, scale]
metrics:                         # 只放已驗證、非機密的數字
  - "訓練樣本 5,000 → 5,000,000"
  - "場張量 up to 2048×2048；1–2 GPU；TAT < 16h"
verified: Wei 口述 2026-09-12（Grill-Me, aetherAI）
phrasings:                       # 已核可的英文句子，CV 直接取用
  - "Initiated and built the data path that scaled usable training samples from 5,000 to 5,000,000."
never_say: ["GPU utilization as headline metric"]
---
自由敘述：背景、決策、取捨、面試可展開的細節。

兩種互動模式

Grooming（每份 JD）Grill（深挖，不綁 JD）
時機草稿組好之後你有空時；或洞見迴圈累積出議程
題數≤ 3，選擇題為主不限，逐段
只問會改變這份草稿的真缺口單薄的 atom（缺數字、缺決策、缺「為什麼」）、跨 JD 高頻缺口
產出定稿 ＋ session 紀錄新／升級的 atom、frame、已核可措辭
時間≤ 5 分鐘30–60 分鐘

主張強度階梯

「不張揚、不低下」的機械定義。每個 bullet 要能追溯到某個 atom，動詞必須落在該 atom 的 role 範圍內。

role允許的英文動詞（上限）不可低於
initiated-and-ledinitiated, designed, built, drove, led不可寫 assisted / supported
ownedowned, built, implemented, maintained不可寫 helped
co-led / second-leadco-led, served as second lead, integrated, tested不可單獨寫 led
contributedcontributed to, implemented part of, tested, validated—
usedused, applied, evaluated不可寫 built / developed
