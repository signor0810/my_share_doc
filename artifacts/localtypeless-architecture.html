Local Typeless 架構

本機語音口述轉成整理好的文字。語音辨識在自己的電腦上跑，文字整理交給遠端 LLM；專為中英夾雜的工程口述設計。Windows、Python、Tkinter。

三條不能違反的原則

  1. 聲音、圖片、附件不離開這台電腦。遠端 LLM 只看得到文字，圖片和檔案在文字裡是 [圖1]、[檔案1] 這種標記。
  2. 斷線不丟字。LLM 連不上、逾時、或輸出沒通過檢查，就改用不需要模型的規則整理，口述內容一定留得住。
  3. Prompt 和詞庫放在程式外面。改檔案就生效，不用改程式、不用重開。

一次口述怎麼走完

在本機執行 送到遠端 LLM（只有文字） 寫到本機檔案
hotkey/daemon.py

1. 按快捷鍵

全域快捷鍵（預設 Alt+Q 開始／停止、Alt+V 貼上參照）。也可以按視窗上的按鈕。

↓
recorder/

2. 錄音並依靜音切段

audio_recorder.py 收麥克風，chunker.py 在停頓處切成一段一段，長口述不用等到最後。

↓
sessions.py、stt/

3. 邊錄邊辨識

每一段交給 faster-whisper。三種跑法可選：cpu_fast、cpu_accurate、gpu_local；GPU 起不來會自動退回 CPU。

↓
glossary/manager.py

4. 詞庫校正

把聽錯的專有名詞換回正確寫法（例如把音近的字換成 OPC、EUV）。

↓
ui/draft_window.py、ui/draft_model.py

5. 進到草稿

辨識出的文字出現在草稿框，可以直接改。貼上的截圖、表格、拖進來的檔案變成標記，內容留在本機（capture/、textblocks.py）。

↓
pipeline.py、llm/

6. 整理

依選的模式組出 prompt（模式檔＋個人規則＋詞庫），連同草稿文字送給 LLM。介面是 OpenAI 相容的 Chat Completions，換設定檔就能換服務。

↓
cleanup/guard.py

7a. 檢查有沒有亂加

LLM 可以刪贅字、改排版，不能新增沒講過的內容，也不能弄丟標記。

cleanup/rules.py

7b. 沒通過或連不上

改用規則整理（去贅字、修標點），並標示「未經 LLM」。

↓
output/

8. 送出

貼回上一個視窗（rich_paste.py 會把文字和圖片依順序交錯貼上）、複製到剪貼簿，或附加到筆記檔。

↓
output/record_store.py

9. 存成紀錄

按「完成」存一個 Markdown 檔到 records/年-月/，含整理結果與原文；超過保留天數自動清掉。

整理模式

模式Prompt 檔做什麼
整理prompts/clean.md去贅字、修標點、分段，意思不變
AI 提示prompts/prompt.md把口述改寫成給另一個 AI 的清楚指示
摘要prompts/summary.md濃縮成重點
投影片prompts/slide.md整理成投影片條列
轉換prompts/transform.md依口述的指示改寫選取的文字

每次整理都重新讀檔，所以送給 LLM 的內容是三層疊起來的：<模式>.md（基本指示）＋ <模式>.user.md（教學模式學到的個人規則）＋ {glossary}（詞庫）。

視窗

每個視窗都拆成兩半：不碰 Tkinter 的邏輯（可以直接測試）和只負責畫面的視窗。背景執行緒只把事件丟進佇列，由畫面執行緒取出來更新。

草稿視窗（主視窗）

上面草稿、下面整理結果

  • ui/draft_window.py 畫面
  • ui/draft_model.py 草稿內容與標記
  • ui/draft_bridge.py 背景執行緒到畫面的橋
  • ui/file_drop.py 拖放檔案

資訊面板

Home／History／System prompt

  • ui/info_window.py 畫面
  • ui/info_controller.py 用量統計、歷史、prompt 讀寫
  • System prompt 頁可直接改，按「載入」下一次整理就用新的

檢查口述紀錄

從舊紀錄找出該加進詞庫的詞

  • ui/review_window.py、ui/review_controller.py
  • review/detect.py 規則找候選詞
  • review/advisor.py 請 LLM 補定義

教學模式

從使用者的修改學詞庫與規則

  • ui/teach_window.py、ui/teach_controller.py
  • teach/align.py 比對「聽到的」和「要的」
  • teach/apply.py 寫入個人詞庫與個人規則
